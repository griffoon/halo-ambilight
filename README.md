# Halo

Открытая замена приложению SkyDimo для подсветки за монитором (ambilight).
Живёт в трее, почти не ест ресурсы и не трогает подсветку клавиатуры и другого RGB.

*English summary below.*

## Зачем

У ленты Skydimo хорошее железо, но родное приложение со временем стало хуже:

- новые версии 2.x/3.x тяжёлые и перегруженные настройками;
- подсветка заметно мерцает;
- приложение перехватывает управление RGB у клавиатуры и другой периферии, даже если ты этого не просил;
- исходников нет, поправить что-то самому нельзя.

Halo делает то же главное (лента повторяет края экрана), но легко и предсказуемо.
Код полностью открыт под лицензией Apache 2.0: можно пользоваться, менять и распространять.

## Честно о том, как это сделано

Halo навайбкожен: код писался вместе с ИИ-ассистентом (Claude Code), а я ставил задачи,
проверял на своей ленте и правил то, что не нравилось. Протокол ленты снят со старой
SkyDimo 1.2.1. Работает у меня на SK0124, на других моделях может понадобиться доработка.

Если что-то не работает, есть идея или хочется помочь, открывай issue или pull request,
буду рад. Как это лучше сделать, написано в [CONTRIBUTING.md](CONTRIBUTING.md).

## Что умеет

- **Режимы:** Экран, Цвет, Дыхание, Радуга, Аврора.
- **Экран:** захват через DXGI Desktop Duplication, уменьшение кадра на видеокарте,
  60 кадров в секунду, плавность и насыщенность настраиваются, чёрные полосы фильмов
  обрезаются автоматически.
- **Окно настроек** в стиле Параметров Windows 11 (WinUI 3, Mica) с живым предпросмотром ленты.
  Пока окно закрыто, оно не занимает память.
- **Горячие клавиши** те же, что в SkyDimo: `Ctrl+Shift+Alt` + `↑`/`↓` для яркости,
  `←`/`→` для режима, `F10` чтобы включить или выключить.
- **Автозапуск** вместе с Windows (включается в настройках).
- **Клавиатура и другой RGB** только по желанию: через OpenRGB и только те устройства,
  которые ты сам отметил. По умолчанию Halo их не трогает.

Служба `Halo.exe` весит около 1 МБ и занимает 15–35 МБ памяти при ~1,5% CPU.

## Установка

1. Скачай архив из [последнего релиза](../../releases/latest) и распакуй в любую папку.
2. Закрой SkyDimo и убери его из автозагрузки: два приложения не могут одновременно держать COM-порт.
3. Запусти `Halo.exe`. Значок появится в трее, по клику откроются настройки.

Для окна настроек нужны:

- [.NET 8 Desktop Runtime x64](https://dotnet.microsoft.com/download/dotnet/8.0)
  (`winget install Microsoft.DotNet.DesktopRuntime.8`);
- [Windows App Runtime 2.x](https://learn.microsoft.com/windows/apps/windows-app-sdk/downloads).
  Если его нет, окно само предложит скачать.

Сама служба (подсветка, трей, горячие клавиши) работает и без них.

Настройки и лог лежат в `%APPDATA%\Halo`.

## Поддерживаемые ленты

| Модель | Светодиоды | Статус |
|---|---|---|
| SK0124 | 54: 14 слева, 26 сверху, 14 справа | проверено |
| другие Skydimo | любое число | должно работать, раскладку можно задать в настройках |

Порт определяется сам, номер COM-порта указывать не нужно.

## Как устроено

- **Служба** (`Halo.exe`, Rust): трей, горячие клавиши, захват экрана, эффекты и поток кадров
  на ленту. Кадр уменьшается на GPU через mip-цепочку, в память читается картинка примерно 120×67.
- **Окно настроек** (`ui\HaloSettings.exe`, C#, WinUI 3): общается со службой через localhost,
  порт и одноразовый токен лежат в `%APPDATA%\Halo\ipc.json`.

### Протокол ленты

| | |
|---|---|
| Порт | CH340 (VID 1A86), 115200 8N1 |
| Опознание | шлём `Moni-A`, в ответ приходит `SK0124,<7 байт серийника>\r\n` |
| Кадр | `A d a 0x00 <кол-во hi> <кол-во lo>`, затем RGB на каждый диод |

Если кадры перестают приходить, лента гаснет, поэтому служба шлёт их непрерывно.

## Сборка

Нужны Rust (`stable-x86_64-pc-windows-gnu`), MinGW-w64 и .NET 8 SDK:

```
winget install BrechtSanders.WinLibs.POSIX.MSVCRT --scope user
powershell -ExecutionPolicy Bypass -File build.ps1 -Test
```

Всё соберётся в `dist\`: `Halo.exe` и папка `ui\` с окном.

## English summary

Halo is an open-source, lightweight replacement for the SkyDimo app that drives Skydimo
ambient LED strips behind a monitor. It lives in the tray, mirrors the screen edges at 60 fps
with GPU downscaling, has a native Windows 11 settings window, and never touches your keyboard
or other RGB devices unless you opt in through OpenRGB. It was vibe-coded with an AI assistant
and tested on an SK0124 strip. Issues and pull requests are welcome, see
[CONTRIBUTING.md](CONTRIBUTING.md). Licensed under Apache 2.0.
