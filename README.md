# Halo

Лёгкая замена SkyDimo для подсветки за монитором. Живёт в трее,
клавиатуру и прочий RGB не трогает.

## Как устроено

- **Служба** (`Halo.exe`, ~1 МБ, ~14 МБ в памяти) — трей, горячие клавиши, захват экрана и поток кадров на ленту.
  Экран захватывается через DXGI Desktop Duplication и уменьшается на GPU через mip-цепочку:
  в память читается картинка примерно 120×67, а не весь кадр.
- **Окно настроек** (`ui\HaloSettings.exe`) — нативное WinUI 3: Mica/Acrylic, `SettingsCard`, `SelectorBar`,
  светлая/тёмная/контрастная темы. Запускается по клику на значок в трее, после закрытия не занимает память.
  Работает на Windows App Runtime 2.x и .NET 8, которые уже стоят в системе. Со службой общается через localhost.

## Протокол ленты (снят со SkyDimo 1.2.1)

| | |
|---|---|
| Порт | CH340, 115200 8N1 |
| Опознание | шлём `Moni-A`, в ответ приходит `SK0124,<7 байт серийника>\r\n` |
| Кадр | `A d a 0x00 <кол-во hi> <кол-во lo>`, затем RGB на каждый диод |

SK0124: 54 диода, 14 слева снизу вверх, 26 сверху слева направо, 14 справа сверху вниз.

## Режимы

Экран · Цвет · Дыхание · Радуга · Аврора.

В режиме экрана чёрные полосы фильмов обрезаются автоматически (можно отключить).

## Клавиатура и другой RGB

По умолчанию выключено. Если включить «Синхронизировать через OpenRGB» и отметить устройство,
Halo будет красить его средним цветом ленты через SDK-сервер OpenRGB (порт 6742).
Неотмеченные устройства Halo не трогает.

## Горячие клавиши

`Ctrl+Shift+Alt` + `↑`/`↓` — яркость, `←`/`→` — режим, `F10` — включить или выключить.
Это те же сочетания, что были в SkyDimo.

## Сборка

Нужны Rust (`stable-x86_64-pc-windows-gnu`), MinGW-w64 и .NET 8 SDK:

```
winget install BrechtSanders.WinLibs.POSIX.MSVCRT --scope user
powershell -ExecutionPolicy Bypass -File build.ps1 -Test
```

Всё соберётся в `dist\`: `Halo.exe` и папка `ui\` с окном.

Настройки и лог лежат в `%APPDATA%\Halo`.

## Важно

SkyDimo и Halo не могут одновременно держать COM-порт. Перед запуском закрой SkyDimo
и убери его из автозагрузки.
